# Content Quality Checklist

**Purpose**: validate the evidence and recovery requirements before implementation

- [x] Fifteen real books and their differing contents forms are represented by strict reference v2.
- [x] Markdown heading depth is explicitly weak evidence.
- [x] Numbering, indentation, body order and ambiguity precedence are defined.
- [x] Unlabelled, multiple, multi-column, image-only, absent contents and late-index cases are covered.
- [x] Hierarchy and splitting have independent rules and success criteria.
- [x] Protected text is byte-identical across every rewrite class.
- [x] Diagnostics define location, evidence, confidence and recovery.
- [x] Sidecars and OCR remain derived, bounded worker inputs.
- [x] Review-pack observations are independent from production proposals and cannot fill expectations.
- [x] Reference v1 is rejected and deleted rather than migrated.
- [x] No complete book or copyrighted contents transcription is committed.
