## M1 技术验证

### OQ-009：`book.yaml` 与 manifest 正式 schema

根据既有决策起草并验证：

- `book.yaml` 的独立 `schema_version`
- 标题、alias、元数据和原文件描述
- 目录选择、`display_title`、`display_level` 和 `starts_page`
- `frontmatter`、`body`、`appendix`、`backmatter`
- 编号、代码行号和未知字段处理
- `document-manifest.json` 的独立 `schema_version`
- 页面、稳定块 ID、源位置、文本指纹、资源映射和源文件哈希
- 逐级迁移与未知更新版本拒绝规则

该项是技术 schema 审阅，不重新开启逐字段产品 grilling。

## 后续里程碑前处理

使用真实 EPUB fixture 比较 foliate-js、Readium 相关模块和轻量 ZIP/XML
适配器，不凭 API 印象选型。

### OQ-012：高亮前端实现（M3）

通过浏览器 PoC 验证 Selection/Range 或其他锚点实现，覆盖中文、KaTeX、
行内代码、脚注、特殊块、模板变化和 React Island 边界。

### OQ-013：块内精确偏移规则（M3）

在 OQ-012 PoC 后冻结渲染后可见文本的偏移、空白、公式、软换行和 DOM
映射规则。M1 只生成 NFC 规范化文本和版本化指纹。

### OQ-017：匿名阅读设置（M3）

决定匿名访客只使用站点默认，还是用 localStorage 保存临时主题和字号。

### OQ-018：自动封面模板范围（M5）

确定模板数量、字体来源、CJK/拉丁排版、输出尺寸和纹理资源。

### OQ-019：首页精选书架配置（M5）

确定手动书架数量、每架容量、自动排序窗口以及匿名与管理员布局关系。
