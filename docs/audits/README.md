The dated milestone reports in this directory preserve the evidence recorded for those
releases. Their Markdown, configuration-revision, migration and reference-v2 procedures
are not instructions for the current runtime and must not be rerun against `data/library`.

Current structured-content verification is recorded in
[`content-refactor-acceptance.md`](../operations/content-refactor-acceptance.md).
Current operations follow [`deployment.md`](../operations/deployment.md) and
[`recovery.md`](../operations/recovery.md). Historical performance reports remain evidence
for their recorded code, inputs and environment, not interchangeable current baselines.
